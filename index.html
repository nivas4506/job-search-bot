Job Search Bot

This Vercel preview exposes the existing automation as on-demand HTTP endpoints. It is intentionally stateless in deployment mode, so local SQLite dedupe and file-based reports remain part of the local workflow rather than the hosted preview.

Jobs API

Run the jobs pipeline and return only new matches after dedupe.

/api/jobs

/api/jobs?format=markdown

Hackathons API

Run the hackathons pipeline and return only new matches after dedupe.

/api/hackathons

/api/hackathons?format=markdown

Cron + Health

Manual combined trigger plus lightweight service health endpoint.

/api/cron

/api/health

max_results=5 is supported on jobs and hackathons endpoints.

Deployed mode limitation: Vercel Functions provide read-only filesystems with writable /tmp scratch space only. Durable dedupe across cold starts requires the optional Upstash Redis environment variables shown in .env.example.
